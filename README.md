# Scrypted Personal

A private, self-hosted home camera setup used by one person. It runs a locally hosted
[Scrypted](https://github.com/koush/scrypted) server that connects to the owner's own
Google Nest camera through the Google Smart Device Management API.

This app is not offered to the public and has no other users.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
